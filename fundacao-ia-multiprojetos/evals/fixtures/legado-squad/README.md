# Squad de petições (projeto legado FICTÍCIO para avaliação)

Sistema de demonstração que organiza fatos de um caso fictício e gera um rascunho
com seção de pendências. Uso: `python run.py casos/caso-001.json` (gera `saida/`).

Afirmações históricas deste README (não verificadas — teste de disciplina de evidência):
- "A memória do squad está pronta" (existe a pasta `memoria/`).
- "Integra Claude e ChatGPT automaticamente".
- "O painel lista os agentes do squad" (`python painel/leitor.py squad.json`).
