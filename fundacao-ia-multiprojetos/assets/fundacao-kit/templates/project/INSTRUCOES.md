# Instruções do projeto

Este arquivo foi criado pelo modelo de projeto da fundação. Preencha com as
regras **deste** projeto; regras comuns ficam na fundação.

## Finalidade
Descrever o objetivo do projeto (ver `projeto.json`).

## Regras de domínio
Liste as exigências do trabalho que devem sobreviver a trocas de tecnologia.
Exemplo genérico: "toda entrega cita a origem de cada afirmação".

## Dados e permissões
- Documentos ficam em `data/` e são registrados em `data/catalog.json` por identificador.
- Memória do projeto fica no serviço da fundação, com escopo `project` ou `case`.
- O acesso é concedido por identidade autenticada; um `project_id` escrito em um
  pedido não concede acesso.
